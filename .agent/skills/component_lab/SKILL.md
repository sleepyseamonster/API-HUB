# Component Lab Skill

## Purpose
This skill ensures that every UI element in the API Hub frontend adheres strictly to the "Machine Console" aesthetic in `DESIGN_SYSTEM.md`.

## Instructions
1.  **Industrial Filter**: Before proposing a component, verify it has:
    - Zero/minimal gradients.
    - Solid 1px borders (`#E5E5E5` or `#333333`).
    - Monospaced technical labels.
    - High informational density.
2.  **Token Usage**: Use CSS variables or Tailwind classes derived from the `DESIGN_SYSTEM.md` color palette.
3.  **Component Blueprints**:
    - **Status Badge**: Small, sharp corners, solid background color.
    - **Endpoint Row**: Monospaced font, hover highlight, clear copy button.
    - **Data Card**: Minimal padding, no drop shadow, thin border.

## Usage
Activate this skill whenever the **FRONTEND** agent is creating or refactoring UI components in `/frontend/components`.
