# Transfer Bay

This is the shared handoff folder between Kirk and the assistant.

## Purpose
- Drop files here when you want assistant processing.
- Keep private working files in other folders.

## Default Rule
- Assistant may use files in `transfer-bay/` when asked to process handoff items.
- Assistant should not access sibling folders unless explicitly instructed.

## Recommended Intake Format
Use one file per request. Example name:
- `2026-03-16_endpoint-idea_01.md`

Include:
- Goal
- Input context
- What output you want
- Constraints
- Deadline (if any)
